# 🧠 How I Think About Development

```text
┌─────────────────────────────────────────────────┐
│                                                 │
│              DON'T JUST WRITE CODE              │
│                                                 │
│                  UNDERSTAND IT                  │
│                       ↓                         │
│                  EXPERIMENT                     │
│                       ↓                         │
│                    BUILD                        │
│                       ↓                         │
│                   BREAK IT                      │
│                       ↓                         │
│                  FIX IT BETTER                  │
│                       ↓                         │
│                    SHIP IT                      │
│                                                 │
└─────────────────────────────────────────────────┘
```

### My principles

**01 — Learn by Building**

Tutorials help.

Projects teach.

---

**02 — Question the Output**

AI is useful.

Understanding is essential.

---

**03 — Build Real Things**

A project should solve a problem,
teach a system,
or make someone curious.

---

**04 — Keep Experimenting**

The best learning often happens
while building something slightly
outside your comfort zone.
